# 📝 抖音电商罗盘爬虫 - 日志系统说明

## ✅ 已完成功能

### 1. 日志双路输出
- ✅ **文件记录**：`/logs/crawler-YYYYMMDD.log`
- ✅ **控制台输出**：实时显示在终端
- ✅ **Emoji 标识**：快速识别日志类型

- ✅ 交互式日志查看脚本 `view_logs.sh`
- ✅ 支持实时查看、搜索、统计

## 🚀 快速使用

### 启动服务
```bash

```

启动后会看到：

### 查看日志

**方法 1：使用工具脚本**

```bash

tail -f logs/crawler-$(date +%Y%m%d).log

# 查看最新 100 行
tail -100 logs/crawler-$(date +%Y%m%d).log

# 搜索错误
grep "❌" logs/crawler-$(date +%Y%m%d).log
```

## 🎯 日志级别说明

| 级别 | Emoji | 说明 | 示例 |
|------|-------|------|------|
| INFO | 📝 | 普通信息 | 步骤开始、任务进度 |
| SUCCESS | ✅ | 成功信息 | 登录成功、导出成功 |
| WARNING | ⚠️ | 警告信息 | 页面滚动异常、数据为空 |
| ERROR | ❌ | 错误信息 | 登录失败、入库失败 |
| DEBUG | 🔍 | 调试信息 | 详细的数据解析过程 |

## ⚙️ 自定义配置

如需修改日志配置，编辑 `internal/logic/crawler/crawler.go`：

```go
glog.SetConfigWithMap(map[string]interface{}{
    "path":    "logs",                    // 日志目录
    "file":    "crawler-{date}.log",      // 文件名格式
    "level":   glog.LEVEL_ALL,            // 日志级别
    "stdout":  true,                      // 控制台输出
    "rotate":  true,                      // 轮转
    "daily":   true,                      // 按天分割
    "maxDays": 7,                         // 保留天数
    "maxSize": 10 * 1024 * 1024,         // 单文件最大 10MB
})
```

## ⚠️ 注意事项

1. **工作目录**：确保在正确的项目目录运行服务
2. **磁盘空间**：定期清理旧日志，避免占用过大
3. **日志级别**：生产环境建议设置为 INFO 或 WARNING
4. **敏感信息**：注意日志中不要包含敏感数据

## 🛠️ 故障排查

### 问题 1：日志文件没有生成
```bash
# 检查目录
ls -ld logs/

# 创建目录
mkdir -p logs
chmod 755 logs

# 重启服务
./main
```

### 问题 2：日志不输出到控制台
检查配置中的 `"stdout": true`

### 问题 3：找不到日志文件
```bash
# 查找所有日志文件
find . -name "crawler-*.log"

# 查看最新日志
ls -lt logs/*.log | head -1
```
