## 📊 数据流向

```
爬虫启动
   ↓
1. 检查 Cookie → cookies/cookies.json
   ↓
2. 开始爬取 → 实时日志 → logs/crawler-YYYYMMDD.log
   ↓
3. 保存进度 → checkpoints/task_xxx.json (断点续爬)
   ↓
4. 抓取数据 → 保存到数据库 (MySQL)
   ↓
5. 导出数据 → exports/*.csv, exports/*.xlsx
   ↓
6. 任务完成 → 删除断点文件
```

## 🗄️ 数据库配置

### 配置文件位置
`manifest/config/config.yaml`

### 默认配置
```yaml
database:
  default:
    type: "mysql"
    link: "admin:admin@tcp(127.0.0.1:3306)/easyadmin8?charset=utf8mb4&parseTime=True&loc=Local"
    debug: true
```

### 数据库信息
- **主机**: 127.0.0.1:3306
- **数据库名**: easyadmin8
- **用户名**: admin
- **密码**: admin
- **字符集**: utf8mb4

### 初始化数据库
```bash
# 方法 1：使用命令行工具
mysql -u admin -padmin -h 127.0.0.1 < database/init.sql
```

## ⚠️ 常见问题

### Q1: 为什么没有导出文件？
**A**: 需要先运行爬虫任务才会生成导出文件。
```bash
# 调用爬虫 API
curl -X POST http://localhost:8000/crawler \
  -H "Content-Type: application/json" \
  -d '{"targetUrl":"https://compass.jinritemai.com/shop"}'
```

### Q2: 为什么数据库没有数据？
**A**: 可能原因：
1. 数据库表未创建 → 运行 `database/init.sql`
2. 数据库连接失败 → 检查 MySQL 服务
3. 爬虫任务失败 → 查看日志 `logs/crawler-*.log`

### Q3: 日志文件在哪里？
**A**: `logs/crawler-YYYYMMDD.log`
```bash
# 查看最新日志
ls -lt logs/*.log | head -1

# 查看今天的日志
cat logs/crawler-$(date +%Y%m%d).log
```

### Q4: Cookie 保存在哪里？
**A**: `cookies/cookies.json`
- 首次登录后自动生成
- 下次启动自动使用
- 过期自动清除

### Q5: 如何清理数据？
```bash
# 清理 7 天前的日志
find logs/ -mtime +7 -delete

# 清理所有导出文件
rm -rf exports/*

# 清理 Cookie
rm cookies/cookies.json

# 清理断点文件
rm -rf checkpoints/*
```
