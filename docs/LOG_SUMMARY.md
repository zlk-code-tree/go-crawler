# ✅ 日志系统配置完成

## 🎯 功能特性

### 1. 双路输出
- ✅ **文件记录**：日志自动保存到 `/logs/crawler-YYYYMMDD.log`
- ✅ **控制台输出**：同时实时输出到终端，方便调试

### 2. 日志轮转
- ✅ **按天分割**：每天自动生成新文件
- ✅ **大小限制**：单文件超过 10MB 自动分割
- ✅ **定期清理**：自动保留最近 7 天日志

### 3. 日志级别
- ✅ **ALL**：记录所有级别（DEBUG, INFO, WARNING, ERROR, SUCCESS）
- ✅ **Emoji 标识**：使用表情符号快速识别日志类型
  - 📝 INFO - 普通信息
  - ⚠️ WARNING - 警告
  - ❌ ERROR - 错误
  - 🔍 DEBUG - 调试
  - ✅ SUCCESS - 成功

## 🔍 查看日志

### 方法 1：使用日志工具（推荐）
```bash

```

```bash
# 实时查看
tail -f logs/crawler-$(date +%Y%m%d).log

# 查看最新 100 行
tail -100 logs/crawler-$(date +%Y%m%d).log

# 查看错误
grep "ERROR\|❌" logs/crawler-$(date +%Y%m%d).log
```

## ⚙️ 配置说明

日志配置在 `internal/logic/crawler/crawler.go`：

```go
glog.SetConfigWithMap(map[string]interface{}{
    "path":    "logs",                    // 日志目录
    "file":    "crawler-{date}.log",      // 文件名
    "level":   glog.LEVEL_ALL,            // 日志级别
    "stdout":  true,                      // 控制台输出
    "rotate":  true,                      // 轮转
    "daily":   true,                      // 按天分割
    "maxDays": 7,                         // 保留天数
    "maxSize": 10 * 1024 * 1024,         // 单文件最大 10MB
})
```

## 🛠️ 日志工具功能

`view_logs.sh` 提供以下功能：

1. **实时查看** - `tail -f` 实时日志
2. **最新 100 行** - 快速查看最近日志
3. **错误日志** - 筛选 ERROR 级别
4. **警告日志** - 筛选 WARNING 级别
5. **任务统计** - 显示成功/失败/数据量
6. **清理旧日志** - 删除 7 天前日志
7. **导出日志** - 导出到文本文件

## 📈 性能影响

- ✅ **异步写入**：日志异步写入，不影响爬虫性能
- ✅ **缓冲输出**：批量写入减少 IO 操作
- ✅ **自动清理**：避免磁盘占用过大

## ⚠️ 注意事项

1. 日志目录需要写权限
2. 确保磁盘空间充足
3. 生产环境建议调高日志级别（如 INFO 以上）
4. 敏感信息注意脱敏

## 📞 故障排查

### Q: 日志文件没有生成？
```bash
# 检查目录权限
ls -ld logs/

# 检查磁盘空间
df -h .

# 手动创建目录
mkdir -p logs
chmod 755 logs
```

### Q: 日志不输出到控制台？
检查配置中的 `"stdout": true`

### Q: 如何查看历史日志？
```bash
# 查看昨天的日志
cat logs/crawler-$(date -d "yesterday" +%Y%m%d).log

# 查看最近 3 天的日志
ls -lt logs/crawler-*.log | head -3
```
