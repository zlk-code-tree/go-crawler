# 组织架构佣金统计接口文档

## 接口概述

通过组织架构树状节点作为搜索条件，查询该节点及其直接子节点的佣金统计数据。

---

## 接口信息

| 项目 | 说明 |
|------|------|
| 接口地址 | `GET /api/org/stats` |
| Content-Type | `application/json` |
| 需要登录 | 是 |

---

## 请求参数

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| orgId | int | 是 | - | 组织节点ID |
| preset | string | 否 | thisMonth | 预设时间类型 |
| startDate | string | 否 | - | 自定义开始日期（格式：2026-05-01）|
| endDate | string | 否 | - | 自定义结束日期（格式：2026-05-20）|

### preset 可选值

| 值 | 说明 |
|-----|------|
| today | 今日 |
| yesterday | 昨日 |
| last7 | 近7天 |
| last30 | 近30天 |
| thisMonth | 本月（默认）|
| all | 全部 |

> 说明：如果同时传了 startDate/endDate，优先使用自定义日期范围，preset 失效。

## 响应字段说明

### data（顶层）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| orgId | int | 当前查询的节点ID |
| orgName | string | 当前节点名称 |
| orgType | string | 当前节点类型 |
| startDate | string | 统计开始日期 |
| endDate | string | 统计结束日期 |
| summary | object | 该节点汇总统计（包含所有下属节点数据）|
| children | array | 直接子节点统计列表 |

### summary（统计汇总）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| orderCount | int | 有效订单数 |
| payAmount | number | 订单应付金额（销售额）|
| costAmount | number | 货款（代发价）|
| reserveAmount | number | 留底（销售额的5%）|
| commission | number | 佣金（销售额 - 留底 - 货款）|

### children（子节点）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| orgId | int | 子节点ID |
| orgName | string | 子节点名称 |
| orgType | string | 子节点类型 |
| summary | object | 该子节点的统计汇总（结构同上）|

### 节点类型（orgType）说明

| 类型 | 说明 |
|------|------|
| company | 总公司 |
| branch | 分公司 |
| manager | 组长 |
| group | 小组 |
| employee | 成员 |
| platform | 平台 |
| account | 账号 |

---

## 请求示例

### 1. 查询本月数据

```
GET /api/org/stats?orgId=1&preset=thisMonth
```

### 2. 查询近7天数据

```
GET /api/org/stats?orgId=1&preset=last7
```

### 3. 自定义时间范围

```
GET /api/org/stats?orgId=1&startDate=2026-01-01&endDate=2026-05-20
```

---

## 错误响应

```json
{
  "code": 500,
  "message": "查询失败: 组织节点不存在",
  "data": null
}
```

---

## 数据说明

1. **有效订单**：排除了退款成功、已全额退款、待退货、已关闭的订单
2. **佣金计算公式**：佣金 = 销售额 - 留底 - 货款
   - 销售额 = 商品单价 × 商品数量
   - 留底 = 销售额 × 5%
   - 货款 = 商品代发价 × 商品数量
3. **summary 包含所有下属数据**：选择"济宁"节点时，summary 包含济宁下所有小组、账号的汇总数据
4. **children 只返回直接子节点**：不会递归返回所有层级，如需下级数据请用子节点ID再次调用接口

---

## 配合组织架构树接口使用

先调用 `GET /api/org/tree` 获取组织架构树，拿到节点ID后，再调用本接口查询统计数据。

```
步骤1: GET /api/org/tree          → 获取树形结构，选择节点
步骤2: GET /api/org/stats?orgId=x → 查询该节点佣金统计
```
