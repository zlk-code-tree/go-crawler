# 外链菜单修复总结

## 问题描述
菜单管理新增外链菜单后，获取菜单列表数据时，左侧菜单栏不显示外链菜单。

## 权限类型定义
根据系统设计，`sys_permission` 表的 `type` 字段定义如下：
- **type=1**：目录类型（一级菜单，如"系统管理"）
- **type=2**：菜单类型（二级菜单，如"用户管理"）
- **type=3**：按钮类型（按钮权限，如"新增"、"编辑"、"删除"）

左侧菜单栏应该只显示 `type=1`（目录）和 `type=2`（菜单），不显示 `type=3`（按钮）。

## 修复内容

### 1. 修复 `buildVbenMenuTree` 函数
**文件：** [internal/service/menu.go:245-279](internal/service/menu.go#L245-L279)

**修复内容：**
- 修正 `HideInMenu` 的逻辑：`HideInMenu: r.Hide == 0`
  - `hide=1` 时显示菜单，`HideInMenu=false`
  - `hide=0` 时隐藏菜单，`HideInMenu=true`
- 添加外链菜单特殊处理：当 `ext_url` 不为空时，`component` 设置为空字符串

```go
// 外链菜单特殊处理：component 为空字符串
if r.ExtUrl != "" {
    component = ""
}

item := model.MenuItem{
    Name:      r.Code,
    Path:      r.Path,
    Component: component,
    Meta: model.MenuMeta{
        Title:      r.Name,
        Icon:       r.Icon,
        Order:      r.Sort,
        HideInMenu: r.Hide == 0, // hide=1显示，hide=0隐藏
        Link:       r.ExtUrl,
    },
}
```

## 外链菜单添加规范

在菜单管理界面添加外链菜单时，需要填写：

| 字段 | 说明 | 示例 |
|------|------|------|
| 菜单名称 | 显示在菜单栏的名称 | "百度" |
| 菜单编码 | 唯一标识符 | "external.baidu" |
| 菜单类型 | 选择"菜单" | type=2 |
| 父级菜单 | 选择一个父菜单 | 选择"系统管理" |
| 路由路径 | 前端路由路径 | "/external/baidu" |
| 组件路径 | **留空或填写空字符串** | "" |
| 图标 | 图标名称 | "lucide:external-link" |
| 外链地址 | **完整的URL** | "https://www.baidu.com" |
| 是否显示 | 选择"显示" | hide=1 |
| 状态 | 选择"启用" | status=1 |
| 排序 | 数字，越小越靠前 | 100 |

## 测试 SQL

### 1. 查询所有外链菜单
```sql
SELECT id, name, code, type, parent_id, path, component, ext_url, hide, status, sort
FROM sys_permission
WHERE ext_url != '' AND ext_url IS NOT NULL
ORDER BY sort ASC;
```

### 2. 修复外链菜单状态
如果外链菜单的 `hide=0` 或 `status=0`，执行：
```sql
UPDATE sys_permission 
SET hide = 1, status = 1 
WHERE ext_url != '' AND ext_url IS NOT NULL;
```

### 3. 插入测试外链菜单
```sql
INSERT INTO `sys_permission` 
(`name`, `code`, `type`, `parent_id`, `path`, `component`, `icon`, `ext_url`, `status`, `hide`, `sort`) 
VALUES 
('百度', 'external.baidu', 2, 2, '/external/baidu', '', 'lucide:external-link', 'https://www.baidu.com', 1, 1, 100);
```

## 注意事项

1. **外链菜单的 type 必须是 2**（菜单类型）
2. **外链菜单的 component 必须为空字符串**
3. **外链菜单的 ext_url 必须填写完整的 URL**（包括 http:// 或 https://）
4. **外链菜单的 hide 必须设置为 1**（显示）
5. **外链菜单的 status 必须设置为 1**（启用）
6. **白名单用户（如 admin）无需分配权限，自动拥有所有菜单和按钮权限**
7. **普通用户需要通过角色分配菜单权限才能看到**

## 白名单配置

白名单在 [config.yaml:70-74](config.yaml#L70-L74) 中配置：
```yaml
permission:
  whitelist:
    - admin
    - user1
    - user2
```

白名单用户的特权：
- 自动拥有所有 `type IN (1, 2)` 且 `status=1` 的菜单
- 自动拥有所有 `type=3` 且 `status=1` 的按钮权限
- 无需通过角色分配权限
