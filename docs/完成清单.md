## 📊 数据流向

```
启动爬虫
   ↓
检查 Cookie (cookies/cookies.json)
   ↓
启动浏览器
   ↓
登录检测 → 未登录 → 手动登录 → 保存 Cookie
   ↓
导航到商品榜单
   ↓
分页抓取 → 保存进度 (checkpoints/)
   ↓
获取商品详情
   ↓
获取视频分析
   ↓
保存到数据库 (MySQL)
   ↓
导出文件 (exports/)
   ↓
记录日志 (logs/)
   ↓
任务完成
```

## 🛠️ 常用命令

### 服务管理
```bash
# 启动
./main

# 停止
lsof -ti :8000 | xargs kill -9

# 重启
lsof -ti :8000 | xargs kill -9 && ./main
```

### 数据清理
```bash
# 清理 7 天前日志
find logs/ -mtime +7 -delete

# 清理导出文件
rm -rf exports/*

# 清理 Cookie
rm cookies/cookies.json

# 清理断点
rm -rf checkpoints/*
```

### 数据库备份
```bash
docker exec mysql8 mysqldump -uroot -proot easyadmin8 > backup.sql
```

### 数据库恢复
```bash
docker exec -i mysql8 mysql -uroot -proot easyadmin8 < backup.sql
```

```bash
# 检查 MySQL 连接

```

### 问题 2：数据库没有数据
```bash
# 检查表是否存在
docker exec mysql8 mysql -uroot -proot easyadmin8 -e "SHOW TABLES;"

# 重新初始化
docker exec -i mysql8 mysql -uroot -proot easyadmin8 < database/init.sql
```

### 问题 3：日志没有记录
```bash
# 检查日志目录权限
ls -ld logs/
chmod 755 logs/

# 重启服务
./main
```
