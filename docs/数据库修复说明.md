# 🗄️ 数据库写入问题修复

## ❌ 问题原因

**数据库配置错误**：
- 配置文件中的数据库账号密码是 `admin:admin`
- 实际 Docker MySQL 的账号密码是 `root:root`
- 导致数据库连接失败，数据无法写入

## ✅ 修复内容

### 1. 修复数据库配置
**文件**: `manifest/config/config.yaml`

**修改前**:
```yaml
database:
  default:
    type: "mysql"
    link: "admin:admin@tcp(127.0.0.1:3306)/easyadmin8"
```

**修改后**:
```yaml
database:
  default:
    type: "mysql"
    link: "root:root@tcp(127.0.0.1:3306)/easyadmin8"
```

### 2. 验证数据库连接
```bash

docker exec mysql8 mysql -uroot -proot easyadmin8 -e "SELECT 1;"

# 查看表
docker exec mysql8 mysql -uroot -proot easyadmin8 -e "SHOW TABLES;"
```

```

   ↓
调用 service.TikTokRankingList().CreateBatch()
   ↓
数据库事务批量插入
   ↓
记录任务状态到 crawl_tasks
   ↓
完成 ✅
```

### 数据库服务
`internal/service/tiktok_ranking_list.go`

```go
func (s *sTikTokRankingList) CreateBatch(ctx context.Context, 
    data []*model.TikTokRankingListInput) error {
    
    db := g.DB()
    entity := (*model.TikTokRankingListEntity)(nil)
    
    return db.Transaction(ctx, func(ctx context.Context, tx gdb.TX) error {
        _, err := tx.Model(entity).Ctx(ctx).Insert(data)
        if err != nil {
            g.Log().Error(ctx, "批量插入失败:", err)
            return err
        }
        g.Log().Info(ctx, fmt.Sprintf("成功插入 %d 条记录。", len(data)))
        return nil
    })
}
```
